# AI Smart Fitness Trainer

A premium static showcase for the **AI Smart Fitness Trainer** — a real-time, computer-vision-based fitness web app deployed on Streamlit Cloud.

## 🚀 Live App

👉 **[Launch the Live Demo](https://smart-fitness-trainer.streamlit.app)**

## Features

- 🎯 Real-time pose detection (MediaPipe, 33 landmarks, 42+ FPS)
- 📊 Form score 0–100 across symmetry, ROM, posture, control
- 🔢 Automatic rep counting with state-machine accuracy
- 🎙️ Priority-based voice coaching
- 🧠 ML-enhanced rep quality (Gradient Boosting)
- 📹 Video upload posture analysis
- 🥗 Nutrition / macro calculator (Mifflin-St Jeor)
- 💊 Goal-based supplement guide (educational)
- 📈 Workout history dashboard (Supabase)
